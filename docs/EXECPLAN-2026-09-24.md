# Filmska Teorija: evidence-first release

## Goal
Make module study trustworthy, source-backed, accessible, discoverable, and repeatably deployable.

## Current state
The public Vite SPA has 24 Wikipedia-backed labels, local media and scene notes, a Three.js graph, a static timeline, and a quiz. Essay text is not persisted, lens selection defaults to Feminist, annotations use fixed times, and hash routes have one canonical URL. The Pages workflow only builds.

## Scope
Fix the three trust defects; publish bounded original notes for the eight shortest extracts and three cited worked scene readings; add verified theorist/publication/concept graph paths; generate module entry pages and authored-module sitemap entries; make source refresh explicit and gate deployment with validation, lint, build, and browser smoke.

## Acceptance criteria
- Essay text survives reload per module, and published privacy copy matches behavior.
- A theory lens opens selected when its module opens; direct video tags use real playback time and seek when selected.
- Editorial and case-study claims expose the exact source links used; unreviewed modules are not described as authored.
- Graph edges have source provenance and keyboard-accessible navigation; Three.js loads on demand.
- Modules with a worked scene analysis return HTML with unique title, description, canonical URL, citations, and crawlable links; other module entry pages are noindex until sufficiently authored.
- QA does not fetch or rewrite Wikipedia data; CI runs the same core gates before Pages deploy.

## Risks and release class
R2 public static release. Main risks are inaccurate editorial claims, user note loss, regressions in GitHub Pages subpath routing, and third-party embed privacy. No accounts, backend, paid service, or model calls are added.

## Design
Keep Wikipedia registry immutable during QA. Store authored content separately with explicit citations and validate its module IDs. Generate multipage HTML at build time and hydrate with the existing React app. Use browser localStorage for per-module essay drafts. Keep iframe media manually annotated; synchronize direct HTML5 video only.

## Execution sequence
1. Add sourced editorial registry, case studies, and graph entity data.
2. Update workbench, lens, essay, graph, and module routes.
3. Add page generator, source validator, scripts, CI gates, and tests.
4. Verify locally, review diff, deploy to GitHub Pages, and verify live.

## Verification
Run `npm run source:validate`, `npm run lint`, `npm run build`, `npm run smoke`, and `npm audit --audit-level=high`. Inspect desktop and mobile rendered routes, playback/tag behavior, keyboard graph navigation, generated HTML, sitemap, console, and deployed HTTP/browser state.

## Deployment and rollback
Push verified commit to `main`; GitHub Actions publishes `dist` to Pages. Verify workflow conclusion and live routes. Rollback by reverting this commit and pushing the revert through the same workflow.

## Decisions
Paths enter the sitemap only after a worked scene reading with cited evidence exists. Short study notes remain visible in the app but do not qualify a module for indexing. Scene interpretations are labeled as readings rather than claims made by the cited theorists.

## Outcome
Local QA passed: 24 source modules and 10 editorial notes validated; 10 Playwright checks passed and 2 project-specific cases skipped; the Pages-base preview loaded Auteur at desktop, tablet, and mobile widths with no page errors or horizontal overflow. Dependency audit reported zero vulnerabilities. The 3D graph remains a 533 kB on-demand chunk, and only three worked-analysis module routes are in the sitemap. Live release remains pending.
